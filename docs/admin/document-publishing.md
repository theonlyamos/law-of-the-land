# Document publishing

**Owners:** Content Manager submits; a different Content Reviewer approves and publishes. A Super Administrator may submit, approve, and publish the same version in every environment. **Abort:** the jurisdiction's Gemini search is not ready, the jurisdiction is disabled, source/checksum validation fails, a non-super-admin reviewer equals the submitter, checklist/evaluation is incomplete, step-up fails, or another lifecycle job is non-terminal.

1. In `/admin/documents/<resourceId>`, upload the governed original and invoke `admin/documents:createDocumentVersion` with `{ resourceId, storageId, filename, mimeType, byteSize, sha256, sourceUrl, effectiveAt }`. Expected state is `draft`. Draft, review, and approval make no provider request and create no provider job.
2. Invoke `admin/reviews:submitForReview({ versionId, reason, idempotencyKey })` with a new key. Expected state is `ready_for_review`. A different reviewer invokes `admin/reviews:approveVersion({ versionId, checklistAnswers, evaluationRunId, reason, idempotencyKey })`; every checklist value must be `true`. A `super_admin` may approve their own submission; this role exception is identical in development and production. Expected state is `approved`.
3. In `/admin/review`, choose publish. Password step-up is bound to action `document_publish`, target `versionId`, and the same new idempotency key. Invoke `admin/publication:publishVersion({ versionId, confirmation: "PUBLISH <versionId>", reason, idempotencyKey })`. Only this publish step sends the immutable original for Gemini indexing. Expected state is `publishing`, then `published`; when replacing a version, the previous indexed document is removed before the active pointer changes atomically.
4. Observe the `Index document` job in `/admin/operations`. An accepted upload displays `Waiting for Gemini` and `Next check in {duration}`. Polls occur after 5, 10, 20, 30, then at most 60 seconds. If Gemini does not confirm completion within 30 minutes, the job displays `Indexing needs review` and legal research for the jurisdiction remains paused until an administrator reviews the provider job.

Do not upload draft, review, or merely approved versions to Gemini. Unpublish removes the active indexed document; rollback indexes the selected approved version and removes the former active document through the same durable lifecycle.

Legal research performs one File Search call across the complete server-authorized set of one to four ready jurisdiction stores. Convex remains authoritative for access, titles, URLs, versions, and citations. Never copy Gemini store, document, or operation names into browser-visible notes or incident evidence.

Abort on any unexpected correlation ID, state, or provider outcome. A failed replacement returns the candidate to `approved`, records `Publishing failed. The previous published version is still active.`, releases the safe lock, and preserves the old pointer. A failed first publish records `Publishing failed. No version was published.` Recovery is to open an incident, correct the fault, and start a new approved publication attempt with a new idempotency key; never submit a duplicate provider request for an uncertain outcome. Follow [provider outage and stuck-job recovery](provider-outage.md).
